# fpga_perf_stats
Originally published as part of https://github.com/pConst/fpga_perf_stats    
by Konstantin Pavlov, pavlovconst@gmail.com  

This is a collection of test projects to test absolute performance of various FPGAs   
I wrote Makefiles to run identical tests in various IDEs:   

* Xilinx Vivado
* Quartus Standard
* Quartus Pro

I'm going to add more FPGA devices into testing
